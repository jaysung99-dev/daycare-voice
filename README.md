# 日照語音紀錄 v3

照服員用說的完成每日紀錄。網頁會把一段自然口語整理成結構化表單，交給人確認後存檔；另外附有手機和平板都能用的「操演練習」。

網址：https://jaysung99-dev.github.io/daycare-voice/

## 功能
- **日常紀錄**：講話不必照順序，可以一次講兩位長輩，講錯直接說「不對，是…」。辨識完會產生每位長輩的表單卡片：紅色＝必填或數值不合理，黃色＝請確認（發燒、血壓偏高、未服藥、有意外、名字是依讀音推測的）。每一格右邊的 🎤 可以只補講那一格。
- **操演練習**：系統隨機出一張交班單（基本 5 項或完整 10 項），受訓者用自己的話講出來，系統當場比對評分，並統計各欄位的正確率。結果可以匯出成 CSV，用來回報實際語音環境下的辨識狀況。
- **已存紀錄**：顯示今日進度，資料只存在這台裝置，可匯出 CSV。
- 可以「加到主畫面」，平板會自動改成左右雙欄。

## 會抓的欄位
個案、體溫、血壓、脈搏、飲食（全部／大部分／一半／少量／未進食）、服藥（已服／未服）、如廁次數、如廁協助（需協助／自行）、活動（參加／未參加）、跌倒意外（有／無），外加文字說明與備註。

## 能理解的講法（例子）
- 數字：三十六度八、36度8、三六點七、一百三八十、一四八 九二、高壓一百四低壓九十、上壓／下壓、舒張壓先講、T 37.3／BP 166/98／P 92／HR 64、×3
- 稱呼：秀英阿嬤、阿土伯、土伯、水伯、阿玉姨、陳老太太、林老先生，以及同音誤字（王美鈺、林阿吐、張金睡）
- 口語與台語：藥吞了、吃到碗底、吃得精光、扒了幾口、剩一點點、呷、攏無、家己、兩擺、便所、跋倒
- 簡體字、沒有標點、語助詞（嗯、那個、然後）
- 更正：不對、啊不是、口誤、看錯欄位、刪掉、重量一次、「這組是林阿土的」、只更正舒張壓
- 多人：「兩個人都…」「A和B都有參加」「心率的話A七十八，B七十二」、省略項目的平行句

## 驗證方式與結果
解析規則**只用 dev 集調整**。測試語料由獨立的測試代理撰寫，它看不到程式碼。每一批測試語料只做一次盲測，之後才拿來找錯修正。「無中生有」是指沒講到的欄位卻被填了值。

| 盲測 | 語料 | 欄位正確率 | 無中生有 |
|---|---|---|---|
| 第 1 次 | test.jsonl：120 句／132 筆，與 dev 同一位作者 | 99.1% | 0 |
| 第 2 次 | holdout.jsonl：100 句／110 筆，刻意換新詞彙 | 87.2% | 1 |
| 第 3 次（最終） | final.jsonl：150 句／165 筆，全新作者 | **95.0%**（個案 100%） | 1 |

修正後（已非盲測）：四批共 490 句、539 筆紀錄，欄位正確率 100%；加上模擬語音雜訊（去標點、轉簡體、數字改念中文、插入語助詞）後為 99.6–100%。操演模式另外自動作答 200 題、三種講法，全部滿分。

**結論**：遇到從沒見過的講法時，欄位錯誤率約 5%。錯誤幾乎都是「沒抓到」（留白並標紅），很少「填錯」，而且存檔前一定要經過人工確認。實際上線後用操演模式累積真實語句，就能持續補強。

**沒有測到的部分**：手機實際錄音的辨識品質（受麥克風、口音、環境噪音影響）。這部分請用「操演練習」在現場實測，再匯出 CSV 回報。

## 自己重跑驗證
```
node eval.js eval-final.jsonl            # 欄位正確率
node eval.js eval-final.jsonl --noise    # 加模擬語音雜訊
node eval.js eval-final.jsonl --fails    # 列出每個錯誤
```

## 給其他 AI（例如 Codex）交叉驗證的提示
> 請 clone 這個 repo，不要修改 parser.js。另外寫 100 句台灣照服員口述的每日紀錄，並依照 eval-dev.jsonl 的格式標好正確答案（10 個欄位）。用 `node eval.js 你的檔案.jsonl --fails` 執行，回報欄位正確率和錯誤清單。

## 隱私
這是 demo，名單裡的名字是虛構的。資料只存在使用者自己的瀏覽器（localStorage），不會上傳。正式使用前，請另外評估個資保護與資料備份方式。
